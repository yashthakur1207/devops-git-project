# DevOps Git Project

## Overview

This project demonstrates Git and GitHub best practices for managing a DevOps project using version control.

## Objectives

- Use Git for version control
- Create and manage branches
- Follow feature-based development
- Use Pull Requests
- Maintain project documentation
- Use `.gitignore`
- Create Git tags and releases

## Git Workflow

The project follows this branching strategy:

main
↓
dev
↓
feature branches

### Branches

- `main` - Production-ready code
- `dev` - Development branch
- `feature/*` - Individual features or changes

## Tools Used

- Git
- GitHub
- Markdown
